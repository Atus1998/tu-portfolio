# Tu Nguyen — Portfolio

Static Next.js site. All text is in `data/profile.ts`.

## Run locally
```bash
npm install
npm run dev      # http://localhost:3000
```

## Before you publish
1. Open `data/profile.ts` and fill `upwork`, `github`, `linkedin` (empty = hidden).
2. Optional: copy your CV PDF into `public/` and set `cv: "/Tu_Nguyen_CV.pdf"`.
3. Check every sentence is true for you.

## Deploy free on Vercel
1. Push this folder to a new GitHub repo.
2. vercel.com → Add New Project → import the repo → Deploy (no settings needed).
3. Run PageSpeed Insights (pagespeed.web.dev) on the live URL and screenshot the score for Upwork.
